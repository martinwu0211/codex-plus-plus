本轮完成源码整改：

- 搜索不调用grep，按字面关键词匹配；以减号开头的查询无法变成进程参数。
- read/list/search统一过滤敏感文件及目录，覆盖.env变体、pem/key私钥、SSH凭据、npm/Git凭据等。
- 不跟随符号链接；实际文件读取使用目录FD与O_NOFOLLOW，防止检查后替换链接越界。
- Git 查询改用私有临时元数据快照，仅复制 HEAD/index/refs/常规对象文件，不复制 config、hooks、objects/info 或 promisor 配置。源仓库的 clean/process、fsmonitor、textconv、GPG 和 include 配置不进入查询进程。配置在查询期间被替换也不影响快照。
- 快照最多 128 MiB、20,000 个条目，拒绝元数据符号链接；超过限制或缺少完整对象时拒绝查询。当前仅保证普通 SHA-1、独立 .git 目录仓库，worktree/submodule 元数据文件和 SHA-256 仓库未支持。
- diff 禁用外部程序、textconv 与重命名检测，仅返回经过路径过滤的文件；status 同样过滤敏感路径，禁用路径表达式魔法。
- 搜索 schema 只要求 query，path 保持可选。认证严格匹配完整 /mcp/<secret> 并进行常量时间比较；最低密钥长度 32 字符。
- 日志不记录密钥、请求路径或 User-Agent，仅记录已认证调用并轮换（单份 5 MB，保留上一份）。增加连接超时、1 MB 请求限制、JSON-RPC 输入校验和 Origin 白名单。
- 删除桥中的本机绝对路径注释。
